# USSD Emulator

A lightweight, browser-based USSD emulator for developers.

Test and debug your USSD callback without connecting to a telecom gateway. Configure your callback URL, start a session, interact with your USSD flow, and inspect requests and responses from one interface.

## Features

- Simulate USSD sessions
- Configure custom callback URLs
- Interactive USSD interface
- Request and response logs
- Request and response inspection
- HTTP status and response timing
- Error visibility
- Local session and log persistence

## Guide

For detailed usage, callback configuration, troubleshooting, and USSD integration information, visit the **[Guide](/guide)**.

## Setup

Install dependencies:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

The application runs at `http://localhost:3000`.

## Production

Build the application:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

For deployment information, see the [Nuxt deployment documentation](https://nuxt.com/docs/getting-started/deployment).
